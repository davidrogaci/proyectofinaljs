# Calculadora de Préstamos

Una calculadora de préstamos moderna y accesible que permite calcular cuotas mensuales, intereses y amortización de forma sencilla.

## Características

- 🎯 **Cálculo preciso**: Calcula cuotas mensuales, intereses y amortización
- 🎨 **Diseño moderno**: Interfaz limpia y profesional
- ♿ **Totalmente accesible**: Compatible con lectores de pantalla y navegación por teclado
- 🌓 **Modo oscuro**: Se adapta automáticamente a las preferencias del sistema
- 📱 **Responsive**: Funciona perfectamente en dispositivos móviles y de escritorio
- 💾 **Persistencia**: Guarda los últimos datos ingresados

## Tecnologías Utilizadas

- HTML5 semántico
- CSS3 moderno con variables personalizadas
- JavaScript vanilla
- SweetAlert2 para notificaciones
- Font Inter de Google Fonts

## Instalación

1. Clona este repositorio:

```bash
git clone https://github.com/tu-usuario/calculadora-prestamos.git
```

2. Navega al directorio del proyecto:

```bash
cd calculadora-prestamos
```

3. Abre `index.html` en tu navegador o utiliza un servidor local.

## Uso

1. Ingresa el monto del préstamo en pesos
2. Especifica la tasa de interés anual en porcentaje
3. Define el plazo del préstamo en meses
4. Haz clic en "Calcular"
5. Explora los detalles de cada cuota haciendo clic en "Ver Detalle"

## Accesibilidad

Este proyecto sigue las mejores prácticas de accesibilidad web:

- Estructura semántica HTML5
- Atributos ARIA para lectores de pantalla
- Contraste de colores adecuado
- Navegación por teclado
- Soporte para modo oscuro
- Reducción de movimiento opcional
